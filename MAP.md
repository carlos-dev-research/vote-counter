# MAP

A guide to every file in this repository, for agents and humans.
**Rule:** any change that adds, removes, renames, or changes the purpose of a file updates
this map in the same change. Generated or ignored paths (`node_modules/`, `.wrangler/`,
`public/assets/`, `.env`) are listed but not tracked.

## Root

| Path            | What it is |
|-----------------|------------|
| `CLAUDE.md`     | Rules and context for AI agents: goal, non-negotiable rules, commands, conventions. Start here. |
| `MAP.md`        | This file. A description of every file in the repo. |
| `README.md`     | Short human-facing intro and quick start. |
| `.env.example`  | Template for `.env`: pinned `BUN_VERSION` and `WRANGLER_VERSION`, plus placeholder local secrets (`ADMIN_EMAIL`, `ADMIN_PASSWORD`, `SESSION_SECRET`). Committed. |
| `.env`          | *(git-ignored)* Your local copy of `.env.example` with real values. `wrangler dev` loads it. |
| `.gitignore`    | Ignore rules. The block at the end covers this project (`.wrangler/`, `public/assets/`, `.dev.vars`, and the `!.env.example` exception). |
| `package.json`  | Dependencies and scripts (`build`, `dev`, `deploy`, `typecheck`, `test`, `db:migrate:*`). `packageManager` pins Bun. |
| `bun.lock`      | Bun lockfile. Generated by `bun install`, committed. |
| `tsconfig.json` | Strict TypeScript config shared by the worker and client code (type-check only; nothing is emitted). |
| `wrangler.jsonc`| Cloudflare config: Worker entry point, Static Assets (`public/`, worker-first for `/api/*` and `/v/*`), D1 binding `DB`, compatibility date. |

## src/worker/ (backend, runs on Cloudflare Workers)

| Path                          | What it is |
|-------------------------------|------------|
| `src/worker/index.ts`         | Worker entry point. Hono app that mounts the routers, serves `/v/:slug` → `vote.html`, and returns JSON 404/500. |
| `src/worker/env.ts`           | `Env` (bindings + secrets) and the `AppEnv` Hono generic type. |
| `src/worker/routes/public.ts` | Voter API: `GET /api/campaigns/:slug`, `POST /api/campaigns/:slug/votes`. *(stubs, return 501)* |
| `src/worker/routes/admin.ts`  | Back office API under `/api/admin/*`: login/logout, campaigns, categories, candidates, status, QR. *(stubs, return 501)* |

## src/client/ (browser scripts, bundled by `bun build` into `public/assets/`)

| Path                   | What it is |
|------------------------|------------|
| `src/client/login.ts`  | Script for `login.html`: submits credentials, then redirects to `/admin`. *(stub)* |
| `src/client/admin.ts`  | Script for `admin.html`: manage campaigns, categories, candidates; live counts; QR code. *(stub)* |
| `src/client/vote.ts`   | Script for `vote.html`: reads the slug from `/v/:slug`; shows the ballot, "not open yet", or results. *(stub)* |

## public/ (static files served as-is by Workers Static Assets)

| Path                 | What it is |
|----------------------|------------|
| `public/index.html`  | Landing page at `/`. |
| `public/login.html`  | Admin login page at `/login`. |
| `public/admin.html`  | Back office page at `/admin`. |
| `public/vote.html`   | Voter page. Served by the worker at `/v/:slug`. |
| `public/styles.css`  | Shared mobile-first styles, light and dark. |
| `public/assets/`     | *(git-ignored build output)* Bundled `login.js`, `admin.js`, `vote.js`. |
