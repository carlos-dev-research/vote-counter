# MAP

A guide to every file in this repository, for agents and humans.
**Rule:** any change that adds, removes, renames, or changes the purpose of a file updates
this map in the same change. Generated or ignored paths (`node_modules/`, `.wrangler/`,
`public/assets/`, `.env`) are listed but not tracked.

## Root

| Path            | What it is |
|-----------------|------------|
| `CLAUDE.md`     | Rules and context for AI agents: goal, non-negotiable rules, security rules, commands, conventions. Start here. |
| `MAP.md`        | This file. A description of every file in the repo. |
| `README.md`     | Short human-facing intro and quick start. |
| `.env.example`  | Template for `.env`: pinned `BUN_VERSION` and `WRANGLER_VERSION`, plus placeholder local secrets (`ADMIN_EMAIL`, `ADMIN_PASSWORD`, `SESSION_SECRET`). Committed. |
| `backups/`      | *(git-ignored)* Production database exports made by `bun run ship` before migrations. Contains voter data. |
| `.env`          | *(git-ignored)* Your local copy with real values. `wrangler dev` and `bun run smoke` both read it. |
| `.gitignore`    | Ignore rules. The block at the end covers this project (`.wrangler/`, `public/assets/`, `.dev.vars`, `backups/`, and the `!.env.example` exception). |
| `package.json`  | Dependencies and scripts (`setup`, `build`, `dev`, `typecheck`, `test`, `smoke`, `db:migrate:*`, `ci:build`, `ship`, `ship:check`). `packageManager` pins Bun. |
| `bun.lock`      | Bun lockfile. Generated by `bun install`, committed. |
| `tsconfig.json` | Strict TypeScript config for the worker, shared code, tests, and scripts (Workers types, no DOM). |
| `wrangler.jsonc`| Cloudflare config, committed as the source of truth: Worker entry point, custom-domain route (`workers_dev` off), Static Assets (`public/`, worker-first for `/api/*` and `/v/*`), D1 binding `DB`. `REPLACE_WITH_*` placeholders are filled and committed by the first `bun run ship`. |

| Path                   | What it is |
|------------------------|------------|

## src/worker/ (backend, runs on Cloudflare Workers)

| Path                          | What it is |
|-------------------------------|------------|
| `src/worker/index.ts`         | Worker entry point (Hono). Security headers (CSP), `csrf()` and a secrets check on `/api/*`, mounts the routers, serves `/v/:slug` → `vote.html`, JSON 404/500. |
| `src/worker/env.ts`           | `Env` (bindings + secrets) and the `AppEnv` Hono generic type. |
| `src/worker/routes/admin.ts`  | Back office API under `/api/admin/*`: login/logout/session, campaigns CRUD, status transitions, categories, candidates, QR SVG. Enforces the edit rules. |
| `src/worker/routes/public.ts` | Voter API: `GET /api/campaigns/:slug` (draft/open/closed views), `POST /api/campaigns/:slug/votes`. |
| `src/worker/lib/auth.ts`      | Admin credential check (constant time), signed 12 h `vc_admin` session cookie, `requireAdmin` middleware. |
| `src/worker/lib/device.ts`    | `deviceId` middleware: reads or issues the signed 1-year `vc_device` cookie. |
| `src/worker/lib/crypto.ts`    | HMAC sign/verify (Web Crypto), `safeEqual`, `randomSlug`. |
| `src/worker/lib/db.ts`        | Every D1 query, bound parameters only. Votes are inserted in one atomic batch. |
| `src/worker/lib/ballot.ts`    | Pure logic: group candidates into categories, voter ballot (no counts), results with winners and ties, vote membership checks. |
| `src/worker/lib/validate.ts`  | Input validation: names, UUIDs, slugs, status transitions, vote payload parsing. |
| `src/worker/lib/http.ts`      | `readJson` (JSON-only bodies), `fail` (error response), `isHttps` (Secure cookie flag). |
| `src/worker/lib/qr.ts`        | QR code SVG for the voting URL (`uqr`). |

## src/client/ (browser scripts, bundled by `bun build` into `public/assets/`)

| Path                     | What it is |
|--------------------------|------------|
| `src/client/tsconfig.json` | TypeScript config for browser code (DOM types, no Workers types). |
| `src/client/dom.ts`      | Safe DOM builder `h()` (text nodes only, no `innerHTML`), `mount`, `toast`, `statusBadge`, `bar`. |
| `src/client/api.ts`      | `api()` fetch wrapper for the JSON API; throws `ApiError` with the server's message. |
| `src/client/login.ts`    | Script for `login.html`: submits credentials, then redirects to `/admin`. |
| `src/client/admin.ts`    | Script for `admin.html`: campaign list and create; detail with open/close/reopen/delete, quick-add categories, candidates, live counts (3 s polling), QR (copy, download, present full screen). |
| `src/client/vote.ts`     | Script for `vote.html`: reads the slug from `/v/:slug`; not open yet, ballot, thank-you, results with winners. No auto-refresh: voters reload or tap Refresh. |

## public/ (static files served as-is by Workers Static Assets)

| Path                 | What it is |
|----------------------|------------|
| `public/index.html`  | Landing page at `/`, with a link to sign in as organizer. |
| `public/login.html`  | Admin sign-in page at `/login` (form markup lives here). |
| `public/admin.html`  | Back office shell at `/admin` (rendered by `admin.js`). |
| `public/vote.html`   | Voter page shell. Served by the worker at `/v/:slug` (rendered by `vote.js`). |
| `public/styles.css`  | All styles: design tokens (blue palette), light/dark, cards, forms, buttons, badges, ballot choices, result bars, QR presenter. No inline styles (CSP). |
| `public/_headers`    | Security headers (CSP, nosniff, frame-deny) for static files. |
| `public/assets/`     | *(git-ignored build output)* Bundled `login.js`, `admin.js`, `vote.js`. |

## test/ (`bun test`, pure functions only, no database)

|-------------------------|------------|

| `test/validate.test.ts` | Names, ids, lifecycle transitions, vote payload parsing. |

## scripts/

| Path               | What it is |
|--------------------|------------|
| `scripts/ship.ts`  | `bun run ship` production deploy: checks (git clean, pushed `main`, Bun version, login), creates resources once (D1, hostname → commits `wrangler.jsonc`), build gate, migration safety (backup, destructive-SQL confirmation, open-campaign warning), adds only missing secrets, deploys, health check, `deploy-*` git tag. `--dry-run`, `--smoke`. |
| `scripts/deploy-lib.ts` | Pure helpers for `ship.ts`: JSONC parse/edit, hostname/email validation, pending migrations, destructive-SQL detection, whoami parsing, deploy tag. |
| `scripts/smoke.ts` | End-to-end test against a running server (`bun run smoke`, default `http://localhost:8787`): full campaign lifecycle with simulated phones, duplicate/invalid/CSRF rejections, results. `--keep` leaves the campaign for UI inspection. |
